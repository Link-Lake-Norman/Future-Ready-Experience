Future Ready™ Administrator Command Center

Adds:
- /ambassador/admin/command-center
- Admin Center link in top navigation
- Live browser-based summary of professionals, projects, tasks, messages, and operations
- Current session snapshot
- Alerts
- One-click access to every pilot tool

Install:
cd ~/future-ready-v2
unzip -o ~/Downloads/Future-Ready-Admin-Command-Center.zip -d ~/future-ready-v2
npx tsc --noEmit

Open:
http://localhost:3000/ambassador/admin/command-center
